## Overview

Resource Monitor overlays depletion timers on ore patches and displays per-mine extraction rates in a configurable HUD panel, letting you plan expansion routes before a patch runs dry.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Resource Monitor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Depletion Timers** | Per-patch countdown to exhaustion based on current extraction rate |
| **Flow Dashboard** | HUD panel with real-time ore-per-second for every active patch |
| **Alert Threshold** | Configurable warning when a patch drops below a set percentage |
| **Map Overlay** | Color-coded resource map showing patch health at a glance |
